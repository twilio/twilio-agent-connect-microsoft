# Pinned dependencies for the Hosted Agents deployment.
#
# Installs twilio-agent-connect-microsoft[hosted-agents] plus the Azure
# OpenAI provider for Agent Framework. We intentionally avoid the
# `agent-framework` metapackage (it pulls every provider via
# agent-framework-core[all] and roughly triples the image size).
#
# To switch providers, swap `agent-framework-openai` for the relevant
# `agent-framework-<provider>` wheel and update agent.py.
#
# Regenerate: in a clean venv, install the top-level requirements below
# and ``pip freeze`` (with --prerelease=allow — the azure-ai-agentserver
# betas require it). pydantic is pinned to a stable release below;
# --prerelease=allow otherwise lets it float to an alpha.
#
# twilio-agent-connect-microsoft installs from PyPI with the
# [hosted-agents] extra (TACHostedAgentsApp shipped in 1.1.0).
#
# The Hosted Agents runtime packages (azure-ai-agentserver-*) and their
# transitive deps are pinned below too — they otherwise arrive only via
# the `[hosted-agents]` extra, whose `<2`/`<3` ceilings would let pip pull
# a newer beta and break reproducibility. Versions match this repo's
# uv.lock; bump them together.
