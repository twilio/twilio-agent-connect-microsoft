# Pinned dependencies for the Hosted Agents deployment.
#
# Installs twilio-agent-connect-microsoft[hosted-agents,agent-framework]
# plus the Azure OpenAI provider for Agent Framework. We intentionally
# avoid the `agent-framework` metapackage (it pulls every provider via
# agent-framework-core[all] and roughly triples the image size).
#
# To switch providers, swap `agent-framework-openai` for the relevant
# `agent-framework-<provider>` wheel and update agent.py.
#
# Regenerate: in a clean venv, install the top-level requirements below
# and ``pip freeze``.
#
# NOTE: twilio-agent-connect-microsoft is installed from the vendored
# wheel under wheels/ (see the Dockerfile), NOT from PyPI. The published
# 1.0.1 doesn't yet include TACHostedAgentsApp. Once the next minor
# version ships to PyPI, drop the vendored wheel + its install step in
# the Dockerfile and add this line here:
#   twilio-agent-connect-microsoft[hosted-agents,agent-framework]>=1.X,<2
#
# The Hosted Agents runtime packages (azure-ai-agentserver-*) and their
# transitive deps are pinned below too — they otherwise arrive only via
# the wheel's `[hosted-agents]` extra at Dockerfile build time, whose
# `<2`/`<3` ceilings would let pip pull a newer beta and break
# reproducibility. Versions match this repo's uv.lock; bump them together.
